# CC Hub

A baby-blue Sims 4 custom-content discovery website.

## Preview locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your `cc-hub` GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then Save.
5. Wait a few minutes for the published website link to appear.

## Add your own listings
Open `cc.js` and copy one item object inside the `ccItems` list. Edit its:
- `title`
- `category` (Hair, Clothing, Build & Buy, Makeup, or Accessories)
- `creator`
- `description`
- `image` (for example `images/my-preview.jpg`)
- `link` (the creator's official page or an authorized download)

Put image files inside the `images` folder. Then upload the changed files to GitHub.

Only host downloadable files you created or have permission to redistribute. For creators' paywalled content, link to their official page rather than reposting their files.
